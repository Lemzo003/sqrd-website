    Release status: Development / Not for Construction
    Standalone live dashboard. This page ports the calculation logic from the TW-001 Working Platform Excel design aid (BS 5975-2:2024 screening basis) into a browser tool. Every sketch, gauge and report is generated live from the inputs panel — no macros, plugins, or manual redraws. The plant/excavation schematics are generic, unbranded, parametric illustrations (not a specific manufacturer's model). The bearing-pressure surface (panel 7) is an illustrative visualization of dispersion behaviour — the calculation itself uses a uniform dispersed pressure qz over the dispersed footprint area, per the calculation trace, not the smoothed shape shown. It excludes global stability, layered ground, cyclic degradation, reinforced-platform contribution, buried services, excavations and overlapping influence zones unless separately assessed. This is a development preview, not a released design tool — geometry, references and hold-point logic should be independently checked before any project use.
